# ☕ Starbucks Sales & Performance Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Starbucks Dashboard** built using Microsoft Power BI to analyze and visualize Starbucks-related data. The dashboard is designed to provide meaningful insights through interactive visuals, KPIs, and data-driven analysis.

It helps users explore data, identify trends, and understand key performance indicators through a clean and user-friendly dashboard interface.

---

## 🎯 Project Objectives

- Analyze Starbucks data using Power BI.
- Create interactive visualizations for better data understanding.
- Present important KPIs in a clear and professional format.
- Improve data analysis and visualization skills.
- Build an interactive dashboard for exploring insights.

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Data Visualization** – Charts, graphs, and interactive elements

1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded `.pbix` file in Power BI Desktop.
4. Explore the dashboard and interact with the visuals.
